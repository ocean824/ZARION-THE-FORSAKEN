# ZARION: THE FORSAKEN — Game Design Bible

## Identity
High-expression character-action game centered on stylish combat, weapon/stance switching, supernatural powers, aggressive traversal and spectacle bosses.

## Core loop
Mission/hub → traversal/encounter → style combat → exploration/challenge → miniboss/boss → rank/reward → unlock moves/weapons → replay/mastery.

## Combat
Responsive combo system: launcher, aerial, cancel, dodge/parry, weapon/stance switch, ranged/ability integration, enemy juggling/stagger, style meter/rank and training mode. Flexible Combat/Action RPG Template may accelerate foundation; final system must be purpose-built for character-action responsiveness.

## Enemy design
Enemies are combat vocabulary tests: pressure, armor, ranged control, anti-air, counters, groups and elite variants. Squad/Team Combat AI can inform coordination but should not create unfair off-camera attacks.

## Bosses
Spectacle plus mechanical depth, multiple phases, clear telegraphs, punish windows and style opportunities. Boss assets accelerate animation/prototyping but do not dictate canon.

## Progression
Moveset breadth, weapons, modifiers and mastery challenges—not simple RPG stat inflation. Difficulty changes behavior/composition/timing, not only health/damage.

## V1→V3
V1 proves one playable character, 2 weapons/stances, deep combo sandbox, enemy roster and 2 bosses. V2 expands campaign/characters/weapons/challenges. V3 complete campaign, mastery/endgame, ranking/leaderboards where desired and AXIOM-native build.
