# ZARION — AXIOM Native Build

AXIOM must meet character-action latency/animation/combat requirements before ZARION migration is considered viable.

Required capabilities: high-frequency input, animation blending/motion systems, precise hit/hurt collision, camera, VFX, enemy AI, physics, profiler and deterministic combat test harness.

Shared engine-neutral move definitions/frame windows/style rules and golden combat fixtures come from Unreal. AXIOM parity compares input-to-action latency, frame events, collision outcomes, enemy behaviors and frame time. AXIOM-specific features are added only after reference parity.
