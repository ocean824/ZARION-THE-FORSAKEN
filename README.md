# ZARION: THE FORSAKEN

High-speed character-action game centered on expressive combos, weapon/style mastery, supernatural transformations and spectacle bosses.

## Unreal foundation
Narrative Pro 2 + Ultra Game Template 1.3; Flexible Combat System Framework / Action RPG Template evaluated for one combat owner; Titanfall Movement selectively for mobility concepts; Boss AI Toolkit, Boss Animations, BlackMoon/Sci-Fi Myth boss assets for prototyping/reference; Powerful Effect/VFX modules where useful.

## Gates
V1: one playable character, deep combat sandbox, traversal, enemies and boss. V2: campaign, weapons/styles, progression, multiple boss tiers, ranking/replay. V3: expanded characters/challenges/competitive modes where approved + AXIOM edition.
